## 📋 完整的 Callout 語法表

Callout 語法核心是基於標準的 Markdown **引言（Blockquote）** 語法，並在引言後加上特殊標籤。

### 1. 基本語法結構

|**組件**|**語法**|**說明**|
|---|---|---|
|**開始標記**|`>`|必須以 Markdown 引言符號開始。|
|**Callout 標籤**|`[!TYPE]`|必須是方括號 `[]` 包裹的驚嘆號 `!` 和 **類型名稱**（TYPE）。|
|**自定義標題**|`標題文字`|可選。如果不寫，Obsidian 會使用 `TYPE` 作為預設標題。|
|**折疊控制**|`+` 或 `-`|可選。用來控制 Callout 區塊的預設折疊狀態。|
|**內容區塊**|換行後的內容|區塊內的每一行內容都必須以 `>` 開頭。|

#### 完整範例結構

Markdown

```
> [!TYPE 符號] 自定義標題
> Callout 內容行 1
> Callout 內容行 2
```

---

### 2. 折疊控制語法

折疊控制符號 (`+` 或 `-`) 緊接在 `TYPE` 的後面。

|**語法**|**效果**|**範例**|
|---|---|---|
|**`[!TYPE]`**|預設不折疊，且無法折疊。|`> [!NOTE] 普通筆記`|
|**`[!TYPE]+`**|預設為**展開**，但使用者可以手動折疊。|`> [!SUMMARY]+ 預設展開的摘要`|
|**`[!TYPE]-`**|預設為**折疊**，需要使用者點擊才能展開。|`> [!FAQ]- 點擊查看答案`|

---

### 3. 內建 Callout 類型 (TYPE) 列表

Obsidian 支援以下內建的 Callout 類型（大小寫不敏感，但建議使用大寫以保持一致）：

|**顏色組別**|**類型 (TYPE)**|**替代類型 (Aliases)**|**典型用途**|
|---|---|---|---|
|**藍色 (Blue)**|**NOTE**||一般資訊、主要筆記。|
|**綠色 (Green)**|**SUCCESS**|**DONE, CHECK**|完成、成功、確認無誤。|
|**綠色 (Green)**|**TIP**|**HINT, IMPORTANT**|提示、小技巧、重要建議。|
|**藍色 (Blue)**|**INFO**||背景資料、額外說明。|
|**灰色 (Gray)**|**FAQ**|**QUESTION**|常見問答。|
|**灰色 (Gray)**|**ABSTRACT**|**SUMMARY, TOC**|摘要、內容總結、目錄。|
|**灰色 (Gray)**|**QUOTE**|**CITE**|引用語句、引文。|
|**紅色 (Red)**|**ERROR**|**FAILURE**|錯誤、失敗、關鍵錯誤。|
|**黃色 (Yellow)**|**WARNING**|**CAUTION, ATTENTION**|警告、潛在風險、需要注意。|
|**橙色 (Orange)**|**DANGER**|**CRITICAL**|危險、嚴重性高的問題。|
|**紫色 (Purple)**|**BUG**||軟體錯誤、缺陷。|
|**青色 (Teal)**|**EXAMPLE**||提供範例或示範。|
|**青色 (Teal)**|**SEEALSO**|**RELATED**|相關參考資料。|
|**粉色 (Pink)**|**TODO**||待辦事項。|
|**任何字串**|**自定義**||如果輸入的 TYPE 不在列表中，Obsidian 會將其渲染為**預設顏色 (藍色/灰色)**，但仍可作為折疊區塊使用。|

### 範例：使用不同類型與折疊

Markdown

```
> [!TIP] 使用 Ctrl + O 快速切換！
> 這是提高工作效率的關鍵。

> [!WARNING]- 點擊展開查看潛在風險
> 系統升級必須在夜間進行，否則會導致資料丟失。

> [!ABSTRACT]+ 產品會議摘要
> 1. 下週發布 beta 版本。
> 2. 下季度目標是市場擴張 10%。
```
